# SuperDaily — Everyday Grocery, Delivered

Live demo site: a supermarket with a working cart.

**What actually works (in your browser, no server needed):**
- Live search + category filters over real product data
- Cart drawer with quantities, subtotal, delivery (free over $30, else $2.99)
- Cart saved in localStorage; checkout produces an order reference

**Honest limits:** static front-end. No payment is processed and no order is
sent anywhere. Connect a payment provider and backend to sell for real.
